Reward, Value, and Advantage in Reinforcement Learning

A simple, intuitive, and mathematical guide

💡 0. Big Picture

🔎 RL uses three core concepts to judge decisions: reward, value, and advantage.

  • 🎯 Reward: immediate feedback
  • 📈 Value: long-term expectation
  • ⭐ Advantage: whether an action is better than usual

🎮 Analogy: Picking up a coin is reward. Entering a treasure-rich room is high value. Choosing the best path inside that room is advantage.

1. What Is a Reward?

⚡ Reward is the immediate signal from the environment telling how good the last action was.

  • 🟢 Given directly by the environment
  • ⏱ Short-term
  • 🛠 Task-designer defined

Example (robotics): Successful grasp → +1.0; dropping object → -1.0.

2. What Is a Value?

🔮 Value measures the expected future reward from a state.

Vπ(s) = 𝔼π[ Σ γᵏ rₜ₊ₖ | sₜ = s ]
  • 🧭 Looks into the future
  • 📘 Learned, not provided
  • 🏗 Used for planning & prediction

Intuition: A state with zero reward can still have high value if it's near success.

3. Bellman Equation

🔁 The Bellman equation expresses value recursively:

Vπ(s) = 𝔼[ rₜ + γ Vπ(sₜ₊₁) ]

💡 This allows RL to update its estimates using future predictions.

4. Reward vs. Value

Reward Immediate outcome
Value Long-term desirability
  • 🔥 Reward = what just happened
  • 🔮 Value = what will likely happen

⭐ 5. What Is Advantage?

🚀 Advantage answers: “Is this action better or worse than my usual action in this state?”

Aπ(s,a) = Qπ(s,a) − Vπ(s)

✔ Positive advantage → better-than-average action ✘ Negative advantage → worse-than-average

📌 Why RL uses it: Advantage reduces variance and stabilizes policy gradient updates (PPO, A2C, TRPO).

Robot example:

  • Action moving gripper toward object → higher Q → positive advantage
  • Action moving away → lower Q → negative advantage

🤖 6. Robotics Example

🔧 In pick-and-place tasks:

  • Reward is sparse (often 0 until success).
  • Value rises as the robot approaches grasping.
  • Advantage highlights which micro-actions improve grasp success.

Summary:
Reward defines the goal.
Value estimates long-term success.
Advantage tells the robot which action is best right now.
